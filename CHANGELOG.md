# Changelog

## 0.1.0 — development build

Introduced an original academic workspace, fictional institution website, persistent NestJS/PostgreSQL workflows, scoped development sessions, admissions/import/enrolment, teaching/attendance/correction, assessments, logbooks, learning/submissions, requests, offline finance/refunds, CMS, confidential helpdesk, quarantine and evidence export.

Added relational migrations, runtime validation, row locks, expected versions, idempotency, audit/outbox and regression tests. Production identity, provider integrations and several R0/R1 acceptance criteria remain incomplete. Later releases are not implemented. No real-data or production deployment is authorized by this changelog.
