# Role-based task guide

Open the local workspace, select a synthetic identity and click **Open workspace**. The identity picker is intentionally development-only. Use the sign-out icon at the bottom of navigation to change identity. API permissions are independent of visible navigation.

## Admissions

As registrar, use Admissions → New record or Import allotment CSV. CSV headers are `name,email,external_ref,pool_id,department`. The seeded pool ID is `pool-mbbs`. An imported row starts Submitted; import never decides eligibility. Open it, start verification, record independently checked facts, or return it for clarification. Sign in as dean to approve a Verified record. Return as registrar to confirm enrolment. A full pool rejects the operation without partial enrolment.

## Teaching and attendance

Assigned faculty creates a mapped session with a cohort, room and time. Faculty/room/cohort conflicts are rejected. Mark a past/current planned session Conducted, open its register, explicitly choose a status for each learner, save draft or finalize. Finalization locks editing. To amend, submit an Attendance correction using the finalized session ID and student. The dean approves with a reason. Unfinalized evidence and absent approved policy produce Provisional eligibility.

## Assessments and logbooks

Faculty enters marks or explicit absent/withheld/not-assessed states for every learner, saves, and locks/submits. Dean moderates and publishes independently. Students see only their own published marks. Revocation hides results; full revaluation/reissue remains pending.

Students submit competency evidence without patient identifiers. Assigned supervisors verify, return or reject with a review note. Returned evidence can be revised and resubmitted. A stale record asks you to reopen it instead of overwriting another review.

## Learning and requests

Faculty posts a cohort resource or assignment. Students submit using its ID from the detail panel. Faculty reads assigned submissions and records feedback; deadlines block late submissions unless faculty extends them with a reason. Certificate/leave/appeal requests go to the registrar/dean; approval does not issue a certificate or alter marks.

## Finance

Finance issues an invoice in integer paise, with a fee-version reference and due date. Record only independently verified bank/cash receipts. Payment references are unique. Refund requests reserve balance; dean approval is separate from finance confirmation of actual refund completion. No online gateway, settlement reconciliation or live accounting export is connected.

## Content, support and evidence

Editors create and submit content; publishers review/publish it. Revisions preserve the previous approved public text. English/Bengali versions are independent and missing translations show an explicit English fallback.

For a private student concern, choose the Confidential option. Only requester and designated committee see it. Normal helpdesk staff cannot search it. Uploads remain quarantined while scanning is unavailable. Administrators/dean/auditors can freeze a limited academic evidence snapshot and download its manifest/checksum. It does not expose patient information.
